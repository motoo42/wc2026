# 2026 World Cup Simulator

2026 FIFA 월드컵을 **현 시점 상황에 맞춰** 수학적으로 시뮬레이션하는 웹 앱.
대회를 처음부터 돌리는 게 아니라, **지금까지 치러진 실제 결과는 고정**한 채
남은 경기를 확률 모델로 수만~수십만 번 돌려 각 팀의 **라운드별 도달 확률·우승 확률**을 계산한다.

🔗 **사이트 → https://motoo42.github.io/wc2026/**

## 무엇을 볼 수 있나

- **우승 확률 / 라운드별 성적** — 48개국 각각이 우승부터 조별 탈락까지 *어디서 끝날지*의 확률 분포
- **조별리그 시뮬레이션** — 조 통과·조 1위 확률, 진출/탈락 확정 표시, **3위 진출 커트라인** 통계
- **대회 진행** — 실제 결과 기반 *현재 순위표와 토너먼트 대진*(확률 아님), 날짜별로 이동
- **확률 추이** — 대회가 진행되며 각 팀 확률이 어떻게 변해왔는지 시계열 차트
- **단일 시뮬레이션** — 남은 대회를 딱 한 번 굴려 라운드별로 따라가는 "중계" 모드
- **가상 시뮬레이션(if 시나리오)** — 미정 경기에 가상 스코어를 넣으면 확률이 어떻게 바뀌는지
- **경기 일정** — 실제 일정·결과
- **깊은 계산** — 시뮬 횟수를 최대 50만 회까지 올려 정밀화 (백그라운드 계산 + 완료 알림)

## 모델

1. **팀 전력** = FIFA 랭킹 포인트. 경기 결과가 나올 때마다 **FIFA 공식으로 시간순 갱신**(최근 폼 반영)
2. **한 경기** = 포아송 득점 모델 (전력차 → 기대 득점 → 골 샘플링 → 승/무/패·득실)
3. **녹아웃** = 무승부 시 레이팅 가중 승부차기
4. **대회 규칙** = 2026 공식 **48팀 / 12조** 포맷, 공식 타이브레이커(승자승 우선 → 득실 → …), 3위 8팀 배정표
5. **집계** = 몬테카를로 — 남은 일정을 수만 번 돌려 빈도로 확률 산출

## 기술 스택

- **계산 엔진**: Python (+numpy) — 정밀 몬테카를로, 확률 JSON 산출
- **프론트엔드**: React + Vite + TypeScript — 시각화 + 브라우저 내 즉석 재시뮬
- **연결**: 정적 JSON (서버 없음). 브라우저에도 동일 모델을 이식해 if 시나리오·실시간 재계산을 지원
